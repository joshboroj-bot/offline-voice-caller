Help

How to import contacts

  1. Export contacts from your phone as a .vcf file.
  2. Open this app.
  3. Tap Import Contacts.
  4. Select the VCF file from storage.

How to call with voice

For older speakers and Nigerian/Ijaw-accented English, speak naturally. If a name is repeatedly misheard, use “learn [contact name]” so the app can remember the pronunciation locally.

  1. Tap the microphone.
  2. Say “Call John” (or any contact name).
  3. Select the correct contact if multiple match.
  4. Tap Call Now.
  5. Android opens the normal phone dialer.

Important limitation

This is an offline contact/dialing assistant.

The HTML application cannot create a cellular voice connection itself. Calls are handled by your Android phone’s normal telephone system, so normal SIM/network charges may apply.

Browser speech recognition availability varies. Some implementations may require internet access. Contact storage, search, import and export work fully offline.

PWA / Home screen

You can add this page to your Android home screen for a more app-like experience. A fully installable offline PWA normally also needs a manifest.json and service worker; this single-file version still works when opened directly as index.html.

Supported voice commands

  • “Call [name]” / “Dial [name]” / “Phone [name]”
  • “Search [name]” / “Find [name]”
  • “Show contacts” / “Open contacts”
  • “Clear search”

Privacy

Your contacts are stored locally on this device using IndexedDB.

This app does not upload your contacts to a server.

No account is required. No cloud database is required.

Internet access is not required for contact storage, searching, manual dialing, importing or exporting contacts.

Voice recognition uses the browser’s Web Speech API. Depending on your browser and device, speech processing may require a network connection. Contact data itself is never sent by this app.
